# WaterWatch

An IoT-based river water quality monitoring and contamination alert system.

## Monitoring Locations

- Rasuwa
- Trishuli Bazaar
- Nuwakot

## Features

- Python-based virtual monitoring nodes
- Water quality sensor simulation
- Rainfall-triggered contamination events
- SQLite store-and-forward mechanism
- MQTT communication over TLS
- ThingsBoard Cloud integration
- Water quality alarms and monitoring dashboard

## Technologies

- Python 3.10+
- SQLite
- MQTT
- Paho MQTT
- ThingsBoard Cloud

## Installation

1. Clone the repository.
2. Create a virtual environment.
3. Install dependencies using:

   pip install -r requirements.txt

4. Configure your local `.env` file.
5. Run the application:

   python main.py
